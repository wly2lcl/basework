## EDIT-001：统一编辑预览和冲突契约

**前置任务**：BASE-001。依赖尚未完成时，只能调查或细化方案，不能宣称本项已验收。

**先读 / 主要修改范围**：`pkg/tool/builtin/edit.go`、`pkg/tool/builtin/write.go`、`internal/tools/applypatch.go`。首次阅读应确认实际文件/符号，拟新增路径不存在属正常。

**实施步骤**：

1. 核对所有写入口与权限/路径检查。
2. 定义产品层 edit plan 含基线哈希、相对路径、diff 和 operation ID。
3. 实现只生成预览不写盘。
4. 覆盖符号链接、路径穿越和编码/换行。

**验收条件**：

- 预览不会改文件。
- 所有目标都经过权限与路径检查。
- 基线能用于提交前冲突验证，不能只依赖文件时间。

**针对性验证**：go test ./pkg/tool/builtin ./internal/tools -count=1。命令均从仓库根执行；必须记录结果和覆盖边界。

**交付与回填**：代码/文档 diff、必要测试，以及 `docs/development/evidence/EDIT-001.md`。更新看板的状态和证据；有用户可见行为变化时更新对应指南及 STATUS。

**范围外**：不顺手改其他任务；公共 API、存储格式、默认权限的额外变化必须先写明影响并拆分。
