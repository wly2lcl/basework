## 变更

新增文件：

- `internal/jobs/journal.go`：持久化日志核心。
  - `Record`（started/terminal 两种 kind）与 `Journal` 接口、`JSONLJournal` 实现。
  - `Append` 用 `O_APPEND|O_CREATE|O_WRONLY` 追加写，单条一次 `Write`，崩溃最多丢最后一行。
  - `Records` 读取容错：仅最后一行残缺（崩溃截断）可跳过并继续；中间行损坏返回错误。
  - `foldRecords` 把 started/terminal 折叠成任务视图；`History(owner)`、`AllHistory()` 提供只读查询。
  - `ReconcileOwner(owner)`：把无 terminal 记录的 started 任务改记 `interrupted`（重启归并），返回归并条数。
  - `journalStart`/`journalTerminal` 包装器：started 在登记前写、terminal 在 settle 时写。
- `internal/tools/jobs_tools.go`：`NewJobTools(owner func() string, manager *jobs.Manager)` 返回 `job_list`/`job_output`/`job_cancel` 三个工具。
  - `job_list`：合并内存态与持久化历史（内存优先），支持 `all` 跨 owner 列出（受权限门禁）。
  - `job_output`：复用 JOB-002 的 `ReadOutput` 分页读取；`job_cancel`：复用 JOB-003 的 `Cancel`。
  - 越权（owner 不匹配）与不存在统一返回 `ErrNotFound`，不泄露他人任务的存在性。
- `cmd/basework/jobs.go`：CLI 与运行时装配。
  - `basework jobs list`（支持 `--owner` 过滤）与 `basework jobs show <id>`，全部只读：只构造 Manager + 读日志，不调 `Start`，不产生副作用。
  - `jobOwnerHolder`：晚绑定会话 ID（会话 ID 在 Agent 创建后才可得），`Start` 时才解析归属。
  - `newRuntimeJobManagerAt(owner, journalPath, outputDir)` 与 `newRuntimeJobManager(owner)`（日志在 `getSessionDir()/jobs.jsonl`，输出在 `getSessionDir()/job-output`）；`runtimeJobCleanup` 注册为退出清理（先 `CloseOwner` 等执行体收尾，再 `Close`）。
  - `commandSummary`：把命令行折叠成单行摘要，避免日志里出现多行记录。
- `cmd/basework/jobs_test.go`：6 条测试，覆盖 ID 跨进程唯一（同前缀重启不复用）、重启归并走真实路径解析、CLI 渲染、清理顺序、owner 晚绑定。
- `internal/jobs/journal_test.go`：9 条测试，覆盖追加原子写、最后一行残缺容错、中间行损坏报错、折叠、归并幂等、损坏日志拒绝启动。
- `internal/tools/jobs_tools_test.go`：7 条测试，覆盖列表合并、分页、取消、越权同返回 `ErrNotFound`、空日志场景。

修改文件：

- `internal/jobs/jobs.go`：
  - `Options` 增 `IDPrefix`（任务 ID 前缀，含进程随机段，保证跨进程唯一）与 `Journal`（持久化日志）。
  - `Start`/`StartWithOutput` 在同一锁区间内先 `journalStart`（失败则拒绝启动，不产生无日志的任务）再登记。
  - `settle` 调 `journalTerminal`，写失败记入 `Job.JournalErr` 并在 `String` 中可见，不影响终态判定。
- `internal/tools/background.go`：
  - 增 `OwnerFunc func() string`（晚绑定归属，优先于固定 `Owner`）。
  - 增 `NoTimeout bool`：配置显式关闭超时后，`timeout<=0` 不再回落 30s，而是不带 deadline、只受取消控制。
  - 增 `KillGrace time.Duration` 透传给 JOB-003 的终止宽限期。
- `pkg/agent/agent.go` + `pkg/agent/loop.go`：新增可选接口 `SessionIDProvider { SessionID() string }`（不入 `Agent` 接口，避免既有实现者编译失败），`agentInstance` 实现，供 job 归属取会话 ID。
- `cmd/basework/runtime.go`：接线。创建 `jobOwnerHolder` → `newRuntimeJobManager` → `NewJobTools` 进 `runtimeTools` → `runtimeJobCleanup` 注册进清理插件；Agent 构造完成后 `holder.Set` 会话 ID。
- `cmd/basework/main.go`：`rootCmd.AddCommand(jobsCmd)`。
- `cmd/basework/runtime_test.go`：`runtimeTools` 签名变更的调用点适配。
- `internal/tools/background_test.go`：补 `NoTimeout`/`DefaultTimeout` 语义测试。

关键决策：

- 日志写在会话目录（`getSessionDir()/jobs.jsonl`），随会话隔离；`ReconcileOwner` 只在新会话启动时对**本 owner** 归并，不触碰其他会话。
- 不自动重放：恢复后的历史任务仅供查看（`jobs list`/`show`、`job_list`/`job_output`），重启归并为 `interrupted` 后不再执行。
- ID 唯一性：`Options.NewID` 默认 `前缀-随机段-序号`，随机段来自进程启动时的一次性生成，跨进程不碰撞。
