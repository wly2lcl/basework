# RUN-003：CLI/TUI 统一接入服务

> **2026-09-14 复审说明**：以下为历史实施记录，不能继续单独支撑当前验收。新发现或依赖回退涉及 A02、A09、A12；详见 [本轮复审报告](REVIEW-2026-09-14.md) 与 [任务卡](../../tasks/06-runtime.md#run-003) 的复审补充。实际状态只维护在 [TASKS](../../TASKS.md)。旧结论保留用于追溯，本轮未修业务代码。

## 基线

- 前置 RUN-002 已完成（同日）：`internal/runtime.Service` 契约 + `LocalService`（串行排队、有界订阅、关闭取消）。
- 改造前的运行路径：CLI（`agent -m` 一次性、REPL）与 TUI（`tui.go` 的 `SetInputHandler`）都直接调 `agt.HandleMessage`；TUI 的流式回调在 Agent 构造时一次性注册（`agent.WithCallback(opts.Callback)`），与运行无关——理论上一次被取消运行的收尾增量可以落进下一次运行的界面。
- 退出路径：CLI/TUI 各自 `defer agt.Close()`，服务的资源（进行中运行、任务管理器）不经由统一入口释放。

## 变更

- **`internal/runtime/callback.go`（新增）**：`CallbackSwitch`——按运行绑定的回调路由器（实现 `agent.Callback`）。Agent 注册的永远是路由器；每次运行绑入当次 UI 回调、结束（成功/取消/报错）立即解绑，解绑后到达的事件（迟到的 flush）一律丢弃。`Unbind(cb)` 只在当前绑定与传入者一致时清除，防误清。
- **`internal/runtime/service.go`**：
  - `LocalDeps` 增 `CallbackSwitch`、`UICallback`；
  - 新增 `StartWithCallback(ctx, input, cb)`（cb 非 nil 时覆盖 UICallback）；`Start` 委托它自动绑入 UICallback；绑定/解绑以 defer 挂在运行的完整生命周期上；
  - `RunEvent` 增 `SessionID`（订阅按会话路由的依据）。
- **`cmd/basework/runtime.go`**：`newRuntimeAgent` 无条件注册 `CallbackSwitch` 为 Agent 回调，`opts.Callback` 改存为 `rt.uiCallback`；`Service()` 把两者传入 `LocalDeps`。
- **`cmd/basework/agent.go`**：one-shot 与 REPL 改走 `rt.Service().Start`；取消语义统一为 `Run.Err == context.Canceled`（REPL 的「[响应被中断]」判断加 `errors.Is`）；退出路径从 `defer agt.Close()` 改为 `defer svc.Close()`（服务负责运行取消→Agent→任务管理器的顺序释放）。
- **`cmd/basework/tui.go`**：`--no-tui` 与 TUI 主分支同样走服务；TUI 的 input handler 调 `svc.Start`；`runTUI` 增加订阅转发 goroutine（RunEvent → `tui.RunEventMsg`），`defer sub.Unsubscribe()` 覆盖全部退出路径。
- **`internal/tui/app.go`**：新增 `RunEventMsg`（RunID/SessionID/Kind/Err）；`App.SessionID` 字段；`Update` 按会话路由——不匹配的事件整条忽略（`lastRunEvent` 作为测试观察点，UI 呈现留给 UI-001）。

## 剩余与交接

- 覆盖边界：会话切换的 UI 能力本身尚未存在（UI-003 交付）；本任务交付的是其路由基础（事件带 SessionID、App 按会话过滤、回调按运行隔离）。
- `RunEventMsg` 目前只做路由与记录（`lastRunEvent`），状态卡片展示由 UI-001 接手。
- TUI 全屏模式的人工实测需真实 TTY，随 UI 系列任务一起做。

## 结论

RUN-003 验收条件逐项满足：CLI/TUI 取消和错误语义一致（同一 `Run.Err` 通道）；旧任务回调不串到新会话（CallbackSwitch 按运行绑定+解绑，机制性保证而非约定）；所有关闭路径回收服务订阅（`defer svc.Close()` + `defer sub.Unsubscribe()` 覆盖退出/错误/取消路径）。任务完成。
