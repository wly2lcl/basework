# SEC-001 验证记录：权限作用域上下文过滤

核对日期：2026-09-17；当前代码候选 `1675f7a`。实现已接入 `internal/permission` 的 Checker、SQLiteStore、Cache、
memory migration、运行时会话/工作区绑定和 SQLite 审计；任务状态因前置 QA-001 尚未收口，

## 基线

规则表已经保存 `scope`、`session_id` 和 `project_id`，但此前匹配接口未接收运行上下文，
不同会话/项目可能误用同一条持久化或缓存决策。

## 变更

本次将上下文契约接入 Checker、SQLiteStore、Cache、memory migration、运行时会话/工作区
绑定和 SQLite 审计。

### 作用域契约

- `global` 始终可匹配；空 scope 按 global 读取，兼容旧规则行。
- 具体性优先级为 `session > project > global`；同一作用域按 `created_at ASC` 选择最早匹配项。
- `session` 规则只有在运行上下文 `SessionID` 非空且相等时命中；`project` 规则同理使用
  `ProjectID`。缺少上下文、ID 不同或未知 scope 时均不命中。
- Checker 切换上下文会清空内存缓存；持久化缓存把自动决定写入所属 session/project，未绑定
  上下文时不写持久化规则。迁移旧内存缓存会保留已知上下文；无上下文的旧 session 规则保持
  无法命中，避免跨会话放大权限。
- Checker 在一次检查开始时固定上下文快照，缓存读写、持久化和审计都使用这份快照；即使
  会话切换与在途检查交错，旧结果也不会写入新会话的内存缓存、持久化规则或审计归属。
- 带参数的缓存决定在持久化时会转义 `path.Match` 通配符，保持具体参数集合的精确匹配，
  不会因为一次 `path=*.txt` 决定而放大成工具级放行。
- 运行时在 Agent 会话 ID 确定后绑定 `SessionID`，并以 `session.WorkspaceID(cwd)` 绑定
  `ProjectID`。审计行新增 `project_id`，旧表启动时自动补列，CLI list/audit 展示关联信息。

## 验证

```bash
CGO_ENABLED=0 go test -tags 'sqlite memory' -count=1 ./internal/permission ./tests ./cmd/basework
CGO_ENABLED=0 go test -race -tags 'sqlite memory' -count=1 ./internal/permission ./cmd/basework
CGO_ENABLED=0 go test -count=1 ./...
```

补充交错回归 `TestCache_StaleContextWriteDoesNotWarmCurrentContext` 和
`TestChecker_AuditKeepsCheckStartContextAcrossPrompt`：分别模拟缓存写入、审批等待在切换
到新会话后完成，确认旧结果仍只归属于原上下文。回环端口可用的
环境中，上述权限、CLI 和完整 `sqlite memory` 测试均通过；无回环权限的沙箱只会在
`httptest` CLI 用例处失败，属于执行环境限制。

以上命令均通过。覆盖内容包括：

- memory `RuleApplies` 缺上下文安全拒绝、Checker 不跨 session、Cache 不跨 session，以及审计
  记录 session/project；
- SQLite 的 session/project/global 优先级、错配隔离、无上下文回退 global、关闭后重开仍保留
  scope、SQLite cache 隔离；
- 旧审计表缺 `project_id` 的启动迁移；空 scope 旧规则按 global 可读；
- memory → SQLite 迁移保留 session 归属，其他 session 不命中；
- race 覆盖 Checker、Cache、SQLite store、审计批量写入和 CLI 依赖包。

## CLI 复核

隔离 HOME 下执行：

```bash
basework permission add --type allow --pattern danger_tool --scope session
# 失败：session 作用域必须提供 --session
basework permission add --type allow --pattern danger_tool --scope session --session sess-cli
basework permission list
```

`permission list` 显示 `作用域 / 会话 / 项目` 列；SQLite 审计查询结果同时带会话和项目 ID。
真实审计字段由 `AuditRecord.ProjectID` 与 `permission_audit.project_id` 保存，未改变默认无
上下文的安全行为。
