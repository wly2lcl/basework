# UI-003 会话切换与可恢复进度

## 基线

- 前置：UI-002、CTX-003 均已完成（看板 22/28）。
- 已有能力：RunEventMsg 按 SessionID 路由（RUN-003）；job 重启归并 interrupted（JOB-004）；工作区事实模型（CTX-001）；file.edited 事件携带 Verify 命令（EDIT-003）；后台任务状态卡片（UI-001，无会话隔离字段）。
- 缺口：无切换时的状态重置；无重启后「哪些操作需重试」的汇总呈现；任务快照无会话隔离。

## 变更

- `internal/tui/resume.go`（新增）：`ResumePanel`——任务列表/最近修改/验证摘要三类事实，`[需重试]` 文字标记 interrupted/failed 任务，任意按键收起；渲染行宽受控。
- `internal/tui/app.go`：
  - `SwitchSession(id)`：重绑会话、清空运行观察点与流式状态、重建任务卡片（复用运行时钩子）、收起恢复面板、系统通知；同 ID 幂等；
  - `SetResumeItems`：装入恢复事实，有需重试项时给出计数通知；
  - `JobStatusMsg` 增加 `SessionID`：旧会话的快照不进入新会话的任务卡片（与 RunEventMsg 同隔离语义）。
- `cmd/basework/resume.go`（新增）：`collectResumeItems`——任务历史（interrupted/failed → 需重试）、工作区事实（file_modified，最多 8 条）、验证摘要（最后一次 committed 的 Verify 命令，附「建议重跑」）；任一路失败不阻塞其余。
- `cmd/basework/tui.go`：App 构造后显式 `SwitchSession(rt.sessionID())`；快照投递带 SessionID（`snapshotMsg` 闭包）。
- `cmd/basework/agent.go`：`getSessionDir` 改为 var 形式（测试可注入隔离目录；生产不变）。
- `docs/TUI.md`（新增）：TUI 操作指南——全局按键、任务卡片、审批弹窗、恢复面板语义与无提示体验检查清单。
