## 验证

### B01 / P1：Close 与 cancel 登记不原子，关闭可能等待外部取消

- 位置：`internal/runtime/service.go`，StartWithCallback 的第二次 closed 检查与第 215–218 行 cancels 登记之间；Close 在互斥锁下清空 cancels 后等待 runGate。
- 已复现：ForRun 回调暂停 Start，Close 完成取消遍历后再放行；Agent 收到的 context 仍未取消。只有测试显式取消调用方 context 才让 Start/Close 结束。
- 影响：关闭/退出遇到这个时序时，不能保证取消在途运行；等待 Provider 或工具自然超时。不是 race detector 会报告的无锁数据竞争。
- 处理：RUN-002。把关闭状态复核和运行 cancel 登记放在同一个同步协议内；所有进入 Agent 的路径必须已纳入 Close 的取消范围。保留排队取消、订阅关闭、资源释放顺序回归；不要持锁调用用户回调。
