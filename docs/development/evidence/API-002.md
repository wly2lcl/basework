# API-002 验证记录：apidiff CI 门禁接线

## 基线

- 日期：2026-11-16；操作者：Qoder AI 会话；系统：macOS arm64；Go 1.26.11。
- 依据 [ADR 0009](../../adr/0009-apidiff-api-compatibility-gate.md) 与 [API-001 评估](API-001.md)；起点 HEAD `484c703`。

## 变更

- 新增 `scripts/check-api.sh`：解析最近 `v*` tag 为基线（可显式传参）；临时 detached worktree 生成基线导出快照；默认与 `sqlite,memory` 两遍对比；核心/扩展层 `Incompatible changes:` 命中即退出 1，实验层仅警告；兼容变更记录不阻断；新增包按新增报告；工具/基线错误退出 2。
- 工具以 `go install` 预装固定版本二进制（`v0.0.0-20261113113407-e3970619a1a4`）：`go run pkg@version` 的模块解析依赖使用者 GOPROXY，`GOENV=off` 会丢掉它导致解析超时（自测首轮实际暴露）；对比阶段只控制 `GOFLAGS`/`GOWORK=off`。
- 新增 `scripts/check-api_test.sh`：临时 git 仓库验证五种协议——无变更放行、兼容新增放行并报告、稳定层破坏拦截、实验层破坏放行并警告、基线缺失显式失败。
- Makefile 新增 `check-api` / `test-api-script`；`build.yml` Quality job checkout 改 `fetch-depth: 0`（浅克隆不带 tags），漏洞门禁后新增两个步骤。
- 文档：validation.md 增加 API 门禁段落；CONTRIBUTING 增加 `make check-api` 指引；release.md 发布门槛加入 API 门禁与三链路要求，并更新过期的 SEC-002 未推送叙述为 SEC-003 已收口事实。
