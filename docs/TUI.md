# TUI 操作指南

`basework tui` 启动交互式终端界面（`--no-tui` 回退简单 REPL）。本文列出按键与
状态语义；运行服务/审批/任务卡片的行为契约见 `docs/STATUS.md`。

## 全局按键

| 按键 | 动作 | 说明 |
|---|---|---|
| `ctrl+c` | 退出 | 运行中触发取消（体现为「[运行已取消]」通知） |
| `ctrl+p` | 命令面板 | 打开命令面板 |
| `ctrl+j` | 后台任务卡片 | 打开/关闭任务列表 |

## 后台任务卡片（`ctrl+j`）

- 列表合并内存态与持久化历史；状态文字标记：`queued`（排队）/`running`（运行中）/
  `succeeded`（成功）/`failed`（失败）/`canceled`（已取消）/`timed_out`（超时）/
  `interrupted`（已中断——上次进程退出时还在跑，需重试）。
- `↑/↓` 选择任务；`enter` 查看输出（分页，最多 30 行/页）；`x` 取消运行中任务
  （终态任务拒绝取消）；`esc` 关闭卡片。
- 列表最多显示 50 条，超出按 ID 截断。

## 权限审批弹窗

交互模式下（配置 `permission.mode: "interactive"`），未被规则放行的工具调用会
弹出审批对话框，展示：工具名、目的、涉及路径、diff 预览、风险依据。

| 按键 | 动作 |
|---|---|
| `y` / `enter` | 允许本次执行 |
| `n` / `esc` | 拒绝（关闭窗口等价拒绝） |
| `↑/↓` | 滚动 diff 预览 |

- 超时未响应（默认 120 秒）自动拒绝。
- 决策不缓存：同一种调用下一次仍会询问。想要永久允许/拒绝请配置权限规则
  （`permission.rules`），不要依赖连续按 y。

## 会话与可恢复进度

- 启动时若上次会话有遗留（中断的任务、失败的命令、未复验的修改），界面顶部
  显示「恢复进度」面板：`[需重试]` 标记的条目建议重跑；任意按键收起面板继续工作。
- 运行结束以文字通知区分：`[运行完成]` / `[运行已取消]` / `[运行失败]`。
- 切换会话（`SwitchSession`）后，旧会话的运行事件与任务快照不会进入新界面。

## 无提示体验检查清单

启动 `basework tui` 后依次确认：

1. 有遗留任务时出现恢复面板，`[需重试]` 条目与 `basework jobs list` 一致；
2. 交互模式下触发敏感操作弹出审批窗，`esc` 关闭后工具未执行；
3. `ctrl+j` 打开卡片，`x` 可取消运行中任务，终态任务提示拒绝；
4. `ctrl+c` 中断运行出现「[运行已取消]」，继续输入不受影响；
5. 退出（`ctrl+c` 两次/`exit`）无残留进程（`jobs list` 中任务标记 interrupted）。
