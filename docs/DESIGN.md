# 设计入口

## 当前有效契约

- [架构与兼容边界](ARCHITECTURE.md)：`pkg → internal`、`internal → cmd` 反向依赖禁止；产品实现通过小接口注入。
- [包契约](reference/README.md)：当前接口、配置、扩展点、模型/调用方体验与限制。
- [架构决定](adr/TEMPLATE.md)：持久化语义、公开接口或运行边界改变时写轻量 ADR；不要以“计划过”为“已实现”。
- [当前状态](STATUS.md)：实现证据与产品验证边界。

## 待实现设计

[路线图](ROADMAP.md) 定义用户目标，[任务卡](TASKS.md) 定义输入、范围、实施步骤和验收。卡片中新增目录、命令和接口都明确属于规划；正式名称必须在实施时核对现有 API。

扩展能力采用“接口定义 → 实现 → 消费者”，每个资源写清创建者、使用范围、退出清理与失败行为。持久化事实与临时 UI 状态分开；模型需要理解的失败应返回结构化结果，而非仅写内部日志。
